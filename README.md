# My Budget Tracker

## About the Project

My Budget Tracker is a simple web application designed to help users track their expenses in one place. The project allows users to enter an expense name, select a category, enter an amount, and view expenses in a table.

## Files in the Project

### index.html
This file contains the structure and content of the Budget Tracker. It includes:
- The main page heading
- The Add Expense form
- Expense categories
- The expense table
- The Budget Plan section
- Budget tips

### style.css
This file controls the visual design of the Budget Tracker. It includes:
- A consistent color palette
- Google Fonts for headings and body text
- Styled forms and buttons
- Styled expense table
- Borders, padding, margins, and rounded corners
- Alternating table row colors
- Card-style sections

### README.md
This file explains the project and describes what each file does.

## Design Features

The project uses a teal, gold, white, and light background color palette. Montserrat is used for headings, while Poppins is used for the main body text.

The Add Expense form and Expense Table are styled with spacing, borders, padding, rounded corners, and consistent colors to make the application clean and easy to use.
